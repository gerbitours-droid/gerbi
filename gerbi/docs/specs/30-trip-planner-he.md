# אפיון מתכנן החופשות של ג׳רבי

המתכנן מחבר בין בקשת חופשה, בחירת יעד ותאריכים מדויקים, חיפוש טיסות ובניית מסלול. המשתמש יכול להתחיל בהקלדה, בהצעה מוכנה או בבחירת תאריכים. שלושת הנתיבים מעדכנים את אותם פרטי חופשה.

## מסך פתיחה ושיחה

- מיתוג ג׳רבי כולל את הכחול, הצהוב, הדמות ותמונת היעד שכבר מופיעים באתר. תיבת הכתיבה במרכז עם הצעות התחלה, קיצור לתאריכים וקיצור לעריכת הנוסעים.
- הצעות ההתחלה שולחות בקשה שלמה לדוגמה. הקלדה רגילה שולחת ב־Enter, ומשאירה שורה חדשה ב־Shift+Enter. השיחה זמינה בעברית ובאנגלית.
- כשיש תשובה, גלריית היעדים מופיעה בראש ההודעה העדכנית. אחריה מוצגים הפרטים שהובנו, שאלת המשך אם נדרש מידע, וקישורים לבניית מסלול ולבדיקת טיסות. פעולות ההמשך ליד תיבת הכתיבה מעדכנות את הבקשה הקיימת.
- לוח פרטי החופשה כולל נוסעים, לילות, תקציב, חודש והעדפות. אפשר לעדכן ולהישאר בשיחה או לעבור לתצוגת האפשרויות. בנייד הלוח מתקפל כדי לפנות מקום לשיחה.

## תאריכים ונוסעים

| מצב | התנהגות |
| --- | --- |
| תאריכים גמישים או חודש מועדף | אפשר לקבל רעיונות מהקטלוג. פעולה לבדיקת טיסות מתוך כרטיס פותחת את לוח השנה בהקשר של אותו יעד. |
| בחירת תאריכים | אפשר לבחור ימים בלוח או להזין אותם בשדות ידנית. במחשב מוצגים שני חודשים ובנייד חודש אחד. הבחירה נשמרת לאחר אישור. Escape סוגר את הלוח בלי להחיל את העריכה. |
| הלוך ושוב | נדרשים יום יציאה ויום חזרה. הטופס מציג את מספר הלילות שנגזר מהטווח. חזרה באותו יום נתמכת בחיפוש טיסות. |
| כיוון אחד | נדרש יום יציאה בלבד. בחיפוש ל־Volero מופיע מקטע הלוך אחד. |
| שינוי או ניקוי תאריכים | שינוי מעדכן את ההמלצות ואת פעולות החיפוש העדכניות בשיחה. כפתור הניקוי מחזיר למצב גמיש ומשאיר את שאר ההעדפות. |
| אילוצי יומן | תאריך בעבר או מעבר לשנת החיפוש חסום. בטווח הלוך ושוב, יום החזרה יכול להיות ביום היציאה או אחריו. |
| נוסעים | סך הנוסעים מוגבל לתשעה. שינוי מהטופס מעדכן את הבקשה ואת מספר הנוסעים שיועבר בחיפוש הבא. |

תאריכים והעדפות נשמרים במכשיר. ההודעות זמינות במהלך הביקור, כולל אחרי מעבר לתוצאות טיסות וחזרה למתכנן. טעינה מלאה של הדף פותחת שיחה חדשה עם הפרטים השמורים.

## המלצות, טיסות ובניית מסלול

- כרטיס יעד כולל תמונה, סיבת התאמה מתוך הקטלוג, אומדן או עונה מומלצת, מועדפים, מפה ובניית מסלול. בחירה בתאריכים מתוך כרטיס מציבה את היעד הזה בראש ההמלצות.
- עם יעד ותאריכים תקפים, לחיצה נוספת על חיפוש טיסות שולחת ל־Volero את היעד, התאריכים והנוסעים. חיפוש רץ רק בעקבות פעולה מפורשת. בחירת תאריכים לבדה מעדכנת את הבקשה.
- מסך הטיסות מציג טעינה, ביטול והודעת שגיאה או תוצאות. כפתור חזרה מחזיר לאותה שיחת מתכנן. תוצאות החיפוש כפופות לזמינות הספק, ואומדני הקטלוג מסומנים כאומדנים.
- בניית מסלול מעבירה לבונה את היעד הנבחר, ואם יש תאריכים מדויקים גם את התאריכים ומספר הנוסעים. בונה המסלולים מנהל את תכנון השהייה והטיסות לפי היכולות שלו. חיפוש כיוון אחד מתוך המתכנן נשאר במסך הטיסות.
- מסלול רב־יעדי עובר לרכיב הרב־יעדי הקיים, עם המקטעים שזוהו בשיחה. חיפוש לפי כרטיס יעד רגיל נשאר פעולה נפרדת.

## תנועה ונגישות

- בכניסה, הרקע, הכותרת, תיבת הכתיבה וההצעות מתגלים ברצף קצר. שליחת בקשה מציגה את בועת המשתמש ואת התשובה, וכרטיסי היעדים נכנסים בהדרגה לאחר ההתאמה.
- לוח השנה נפתח במעבר קצר. בזמן בדיקה נוספת ג׳רבי מציג חיווי עד לקבלת תשובה. בחיפוש Volero המטוס ומקומות השמירה לכרטיסים מוצגים במשך ההמתנה ומתחלפים בתוצאה, שגיאה או ביטול.
- תנועה מושבתת בהעדפת מערכת להפחתת תנועה. מקלדת ומיקוד נשמרים בלוח השנה, בפקדי השיחה ובחזרה מכפתורי העריכה. מצבי טעינה ושגיאה מלווים בטקסט.

## מחיקה ואיפוס

מחיקת הודעות משאירה את פרטי החופשה וההעדפות. איפוס מחזיר את השיחה והפרטים לברירת המחדל. שתי הפעולות דורשות אישור, ומועדפים וטיולים שמורים נשארים זמינים.
