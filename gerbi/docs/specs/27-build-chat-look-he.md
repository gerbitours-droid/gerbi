# 27 – "בונים חופשה עם ג׳רבי": מראה צ׳אט

- שם הדף: "בונים חופשה עם ג׳רבי" / "Plan your holiday with Gerbi" (בתפריט העליון נשאר "בונים חופשה").
- במה (מסך מלא): רקע זוהר מתווי ASCII שמתערבלים מתחת לעכבר (בהשראת React Bits Gradient ASCII, קנבס דו־ממדי, נעצר מחוץ למסך ובהפחתת תנועה) – `dist/ascii-bg.mjs`.
- תיבת כתיבה בסגנון צ׳אט (בהשראת prompt-input, צבעי המותג): טקסט שגדל, Enter שולח / Shift+Enter שורה חדשה, כפתור "העדפות" שפותח את הצ׳יפים והחודש, כפתור שליחה עגול. דוגמאות ככרטיסי הצעה.
- שיחה: בועת הלקוח + תשובת ג׳רבי (אוואטר) עם החבילה. אחרי תשובה ראשונה הבמה מתקפלת.
- חזרה למעלה: כפתור "קלע" (בהשראת React Bits Sling Button) – הקשה = גלילה למעלה, משיכה ושחרור = יורה למעלה עם התפזרות נקודות – `dist/sling-top.mjs`.
- ללא שינוי: לוגיקת הבנייה, השרת, מחירים, הזמנה. מזהי הבדיקות נשמרו.
