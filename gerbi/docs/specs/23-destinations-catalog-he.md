# אפיון 23 — קטלוג יעדים (70 יעדים במקום 4)

15.11.2026 · סטטוס: מאושר לבנייה · קוד: `dist/catalog.mjs`, `dist/catalog/*.mjs`, `dist/destinations-ui.mjs`, `dist/destinations.css`, `dist/assets/destinations/`

**ההחלטה במשפט אחד:** כל מה שהאתר מציג כ"יעד" — עמוד היעדים, עמוד יעד, "החופשות שכולם חולמים עליהן" בדף הבית, ההשראה וההמלצות של המתכנן — נשען על קטלוג אחד של 70 יעדים אמיתיים (עברית + אנגלית, תמונה מקומית מורשית, מידע מעשי), ושום העדפה שנשמרה משיחה קודמת לא מסננת יותר את חלון הראווה של דף הבית.

## 1. למה המבקרים ראו "רק יוון" (ממצא, נבדק בדפדפן)

שתי סיבות, שהשנייה מחמירה את הראשונה:

1. **באג — מסנן "יעד מבוקש" שנשמר לתמיד (הסיבה הישירה).**
   - כשמישהו כותב למתכנן "חופשה זוגית ביוון", מנוע ההבנה מתרגם את "יוון" לקודי היעדים `JTR, ATH, HER, RHO` ושומר אותם ב־`state.preferences.want`.
   - `persist()` (pages.mjs) שומר את התקציר כולל `want` ב־`localStorage` (`gerbi-journey-v1`), ו־`restoreJourney` משחזר אותו בכל טעינה.
   - `rankInspirations` (personalization.mjs) **מסנן** — לא רק מדרג — לפי `want`: `(!wanted.length || wanted.includes(id))`. מכיוון שמכל קודי יוון רק `JTR` מקושר לטיול (סנטוריני), דף הבית מציג כרטיס אחד בלבד: סנטוריני, יוון. גם `/results` מציג רק אותו.
   - המצב שורד רענון ונמחק רק בלחיצה על "חופשה חדשה" במתכנן. בעל העסק (שבדק את המתכנן עם יוון) רואה מאז רק יוון.
   - שחזור: מתכנן ← "חופשה זוגית ביוון באוגוסט" ← דף הבית: `['סנטוריני, יוון']`; אחרי רענון: אותו דבר.
2. **דלות מלאי.** הקטלוג הוא 4 טיולי הדגמה (`dist/data.mjs`): סנטוריני, רומא, מלדיביים, דובאי. יוון היא המדינה היחידה עם ארבעה קודי שדה בתעופה במנוע, כך שכל שאלה על "ים" / "זוגי" / "יוון" נוחתת על סנטוריני. גם בלי הבאג, עמוד היעדים מציג 4 כרטיסים בלבד.

**התיקון:** (א) דף הבית לא מסנן לפי `want`/`exclude` מתקציר קודם — יעד שביקשו מקבל קדימות, לא בלעדיות; (ב) דף הבית מציג בחירה מגוונת מהקטלוג: עד 2 יעדים מכל אזור, מדורגת לפי עונה (החודש הנוכחי או החודש בתקציר) ולפי סגנונות שנבחרו; (ג) עמודי היעדים, היעד, ההשראה וההמלצות עוברים לקטלוג. בדיקת רגרסיה: `tests/catalog.test.mjs` מוודא שגם עם `want=[JTR,ATH,HER,RHO]` דף הבית מציג ≥ 3 אזורים.

## 2. מודל הנתונים — `dist/catalog.mjs`

ממשק יציב (נצרך גם ע״י "בונה הטיול הקסום"):

```js
import { destinations, byCode, byId, search, rank } from './catalog.mjs';
```

| שדה | סוג | הערות |
|---|---|---|
| `id` | string | kebab-case יציב. 4 היעדים הקיימים שומרים את ה־id (`santorini`, `rome`, `maldives`, `dubai`) כדי שקישורים וטיולים שמורים ימשיכו לעבוד |
| `code` | IATA | קוד עיר או שדה ראשי. **חייב** להופיע ב־`dist/places.mjs` (בדיקה אוטומטית) |
| `airports` | IATA[] | כל השדות הרלוונטיים; כולם ב־`places.mjs` |
| `name`, `country` | `{he,en}` | |
| `region` | enum | `europe` · `asia` · `americas` · `africa` · `middle-east` · `oceania` · `israel` |
| `tags` | string[] | מאוצר המילים של `backend/tag-catalog.mjs` בלבד (בדיקה אוטומטית). נוספה קבוצה `destination_traits`: `nature, culture, food, nightlife, shopping, ski, luxury` |
| `bestMonths` | 1..12[] | |
| `flightHours` | number | טיסה טיפוסית מנתב״ג (כולל עצירה אם אין ישירה) — הערכה |
| `direct` | bool | יש בדרך כלל קו ישיר מנתב״ג (עונתי נחשב) |
| `budgetLevel` | 1..4 | 1 = זול יחסית, 4 = יקר מאוד |
| `dailyBudgetIls` | `{low,mid,high}` | ₪ לאדם ליום **בשטח — בלי טיסות ובלי לינה** (אוכל, אטרקציות, תחבורה מקומית). הערכה גסה בלבד; מוצג תמיד עם "הערכה" |
| `hotelCity` | IATA אופציונלי | קוד עיר לחיפוש מלונות אצל הספק כשהוא שונה מ־`code` (למשל שדה של אי) |
| `image` | `{src, thumb, alt{he,en}, credit, license, source}` | מגיע מ־`dist/catalog/images.mjs` |
| `summary` | `{he,en}` | 1–2 משפטים |
| `highlights` | `{he,en}[]` | 5–8 |
| `areas` | `{name{he,en}, forWhom{he,en}}[]` | איפה לישון — אזורים, לא מלונות |
| `attractions` | `{name{he,en}, kind, durationH, tags, area?}[]` | 8–15 מקומות אמיתיים. `area` (אופציונלי) = השם האנגלי של אחד מ־`areas` — לקיבוץ ימים. `kind`: `landmark, museum, nature, beach, neighborhood, market, viewpoint, park, experience, religious` |
| `dayTrips` | `{name{he,en}, hours, note{he,en}}[]` | `hours` = נסיעה לכל כיוון |
| `transport` | `{carRecommended, note{he,en}}` | |
| `practical` | `{currency, language{he,en}, timeZone, visaNoteForIsraelis{he,en}, kosher{he,en}, shabbat{he,en}}` | ויזה: ניסוח כללי + "לבדוק במקורות הרשמיים" |
| `seasonsNote` | `{he,en}` | |
| `advisory` | `{he,en}` אופציונלי | יעד שיש לגביו אזהרת מסע של המל״ל — ניסוח ניטרלי + הפניה לאתר המל״ל. יעד כזה לא נבחר לחלון הראווה בדף הבית |
| `trip` | string אופציונלי | קישור לטיול הדגמה ב־`data.mjs` (4 היעדים הישנים) |

עזרים:
- `byId(id)`, `byCode(code)` — לפי `code`, אחר כך לפי `airports`, אחר כך לפי עיר־אב של שדה (CDG → פריז).
- `search(query, lang)` — שם, מדינה, אזורי לינה, אטרקציות ותגיות, בשתי השפות; מדורג (שם מדויק > תחילת שם > מדינה > תוכן).
- `rank(preferences)` — מקבל תקציר בפורמט של מנוע ההבנה (`beach/city/family/couple/relaxation`, `tags`, `month` בעברית/אנגלית/מספר או `start`, `want`, `exclude`, `region`, `maxFlightHours`, `direct`, `budgetLevel`/`maxBudgetLevel`, `kosher`). מחזיר `[{destination, score, reasons:[{he,en}]}]`. `want` מעניק בונוס ולא מסנן; `exclude`, `region`, `maxFlightHours`, `direct`, `maxBudgetLevel` מסננים.
- `curatedPicks({month, preferences, limit, perRegion})` — לחלון הראווה: מגוון אזורים, עונה, בלי יעדים עם `advisory`.
- `regions`, `TAGS_UI` — תוויות לממשק.

הקבצים: `dist/catalog/europe-south.mjs`, `europe-north.mjs`, `east-med.mjs` (טורקיה, גאורגיה, בולגריה, ישראל, מפרץ, מרוקו), `africa-asia.mjs`, `americas-oceania.mjs`. כל קובץ מייצא מערך. `catalog.mjs` מאחד, מוסיף תמונות ומאמת בטעינה (בבדיקות).

**חיבור לשאר המערכת:**
- `places.mjs`: כל קוד וכל שדה בקטלוג קיים (נוספו ~35 מקומות: JMK, FLR, PSA, CTA, PMO, EDI, TFS, FNC, SPU, LJU, INN, SZG, KEF, BGO, RAK, ZNZ, SEZ, MRU, CPT, NBO, HAN, SGN, TYO/NRT/HND, DPS, CMB, GOI, LAS, MCO, CUN, SJO, LIM, BUE/EZE, RIO/GIG, SYD, AKL…) וגם מדינות (יפן, אינדונזיה, מקסיקו…) כדי שהמתכנן יבין אותן.
- `backend/tag-catalog.mjs`: `destinationTags` נבנה מהקטלוג (70 יעדים); 4 הישנים שומרים את התגיות שלהם.
- CMS: `GUIDE_IDS` = כל מזהי הקטלוג. ב־`/admin` מדריך היעד לכל אחד מ־70 היעדים (6 שדות, עברית + אנגלית). ברירת המחדל לשדות מגיעה מהקטלוג.
- מועדפים והשוואה: עובדים על כל יעד בקטלוג (לא רק 4).

## 3. מקור התמונות ורישוי

- מקור: **Wikimedia Commons**, עדיפות לתמונות "Featured" / "Quality images", רוחב ≥ 1600px, לרוחב (יחס 1.3–2.1). רישיונות מותרים בלבד: CC0, Public domain, CC BY, CC BY-SA. (Unsplash דורש מזהה תמונה ידוע מראש; Commons נותן API עם מטא־דאטה של רישוי, ולכן נבחר.)
- עיבוד מקומי: `cwebp` — 1200px (‎≤ 120KB) + ממוזערת 600px. נשמר ב־`dist/assets/destinations/<id>.webp` ו־`<id>-600.webp`. **בלי hotlinking.**
- קרדיט: צלם + רישיון + קישור לדף הקובץ — ב־`ASSETS.md` (טבלה מלאה) וב־`image.credit` שמוצג מתחת לתמונה בעמוד היעד (CC BY/BY-SA מחייבים ייחוס).
- 4 התמונות הישנות (Unsplash) נשארות לטיולי ההדגמה; היעדים בקטלוג משתמשים בתמונות החדשות.

## 4. כללי עריכה

1. עובדות בלבד; מקומות אמיתיים; בלי שמות מלונות, בלי מחירים מומצאים. תקציב יומי = הערכה, מסומן "הערכה" בכל הופעה.
2. עברית טבעית (לא תרגום), גוף שני רבים ("תגיעו", "כדאי לכם"). אנגלית בריטית־ניטרלית.
3. ויזה / כשרות / שבת: ניסוח כללי בלבד + "לבדוק מול המקורות הרשמיים / בית חב״ד" — אף פעם לא הבטחה.
4. אזהרות מסע: ניטרלי, בלי המלצה בעד/נגד; הפניה ל"אזהרות המסע של המטה לביטחון לאומי". סיני לא נכלל (אזהרה גבוהה + מעבר יבשתי); איסטנבול נכללת עם `advisory`.
5. טיסות: "ישירה" רק כשיש קו ישיר מוכר (גם עונתי); שעות = הערכה טיפוסית.

## 5. חוויית משתמש

### 5.1 עמוד יעדים (`#/destinations`)
- חיפוש חופשי (שם, מדינה, אטרקציה, אזור לינה — עברית ואנגלית).
- מסננים (צ׳יפים, מצב ב־URL, ניתנים לשיתוף ולרענון): **אזור** · **סגנון** (ים, עיר, טבע, משפחה, זוגי, תרבות, אוכל, סקי, יוקרה) · **חודש** · **תקציב** (₪ עד ₪₪₪₪) · **משך טיסה** (עד 4 / 6 / 10 שעות) · **טיסה ישירה בלבד**.
- מיון: מומלץ (עונה + פופולריות לישראלים) · זמן טיסה · תקציב · א־ב.
- תצוגה: 12 כרטיסים ואחר כך "הצגת עוד" (+12) — טעינת תמונות `loading="lazy"` עם ממוזערת 600px. מונה "X מתוך 70 יעדים". מצב ריק עם איפוס.
- כרטיס: תמונה, אזור/מדינה, שם, תקציר, שורת עובדות (✈ שעות · ישירה · חודשים מומלצים · ₪₪), לב (מועדפים), השוואה.
- 375px: טור אחד, צ׳יפים בגלילה אופקית, בלי גלילה אופקית של הדף.

### 5.2 עמוד יעד (`#/destination/<id>`)
גיבור עם תמונה + קרדיט · תקציר · "למה לנסוע" (highlights) · מדריך היעד (6 השדות של ה־CMS, ברירת מחדל מהקטלוג, ניתן לעריכה ב־/admin) · איפה לישון · אטרקציות (שם, סוג, משך) · טיולי יום · עונות + 12 חודשים עם סימון · מידע מעשי (מטבע, שפה, אזור זמן, ויזה, כשרות, שבת) · תחבורה · אזהרת מסע (אם יש).
צד: עובדות מהירות + CTA: **חיפוש טיסות** (`#/?to=<code>` — ממלא את שדה היעד בדף הבית) · **בניית טיול מלא** (`#/build?dest=<id>` — בונה הטיול הקסום) · **טיול בהתאמה אישית** (`#/tailor-made?dest=<id>` ממלא את שדה היעדים). ליעד עם טיול הדגמה — גם כרטיס ההדגמה הקיים (מחיר הדגמה, "לתכנון").

### 5.3 דף הבית — "החופשות שכולם חולמים עליהן"
8 כרטיסים מ־`curatedPicks`: מגוון (≤ 2 לאזור), מתחלף לפי העונה, מגיב לצ׳יפי הסגנון. יעד שהמבקר ביקש קודם — ראשון, לא בלעדי. "לכל היעדים" → עמוד היעדים.

### 5.4 השראה (`#/inspiration`) ותוצאות המתכנן
- השראה: אריחי סגנון (משפחות, זוגות, ים, עיר, טבע, סקי, יוקרה, חופשה קרובה) — כל אריח מוביל לעמוד היעדים מסונן, עם תמונה של היעד המוביל באותו סגנון החודש; ומתחת "מומלצים לחודש הזה" (6).
- `/results` מהמתכנן: הטיולים עם מחיר הדגמה נשארים (לא משנים את מנוע ההערכות), ומתחתם "יעדים נוספים שמתאימים" מהקטלוג (`rank`), כך שבקשה ליוון מציגה את יעדי יוון, ובקשה ליפן מציגה את יפן במקום "אין התאמה".
