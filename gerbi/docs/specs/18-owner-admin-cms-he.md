# אפיון 18 — אזור אישי לבעל האתר (ניהול לידים, בלוג ותוכן)

תאריך: 15.11.2026 · סטטוס: מאושר לפיתוח · בעלים: סוכן Owner-Admin/CMS

## 1. מטרה

בעל ג׳רבי טורס צריך לנהל את האתר בלי מתכנת: לטפל בפניות (לידים), לכתוב ולפרסם פוסטים בבלוג, ולעדכן טקסטים באתר (כותרת דף הבית, פרטי קשר, פוטר, באנר הודעה, שאלות נפוצות, מדריכי יעדים). הדף `/leads-admin` הקיים (תיבת פניות בלבד, עם מפתח שנשמר בלשונית) מתפתח לאזור ניהול מלא בכתובת `/admin`.

עקרונות:
- מסד הנתונים היחיד הוא ה־KV (`backend/kv-store.mjs`): Upstash ב־Vercel, קבצים מקומיים בפיתוח. אין תלות חדשה.
- האתר הציבורי עובד גם כשה־API למטה: לכל טקסט יש ערך ברירת מחדל מובנה בקוד.
- כל כתיבה מאומתת ומוגבלת בגודל בצד השרת; כל הצגה מבוצעת עם escape מלא (מניעת XSS).
- המותג בממשק: „ג׳רבי טורס” בלבד. שם הספק לא מופיע בממשק.

## 3. מסכים ומצבים

### 3.1 כניסה (`/admin`, לא מחובר)
- שדה סיסמה + כפתור „כניסה”. noindex, ללא הפניות חיצוניות.
- מצבים: טוען; סיסמה שגויה („הסיסמה שגויה”); יותר מדי ניסיונות (429, „נסו שוב בעוד כמה דקות”); ניהול לא מוגדר בשרת (404, „הגישה לניהול לא הוגדרה בשרת”); שגיאת רשת.

### 3.2 מעטפת (מחובר)
- כותרת „ג׳רבי טורס · ניהול”, כפתור „יציאה”, קישור „לאתר”.
- לשוניות: לידים · בלוג · תוכן האתר · שער מטבע · שיחות שירות. במחשב: עמודה צדדית; בטלפון (375px): פס לשוניות נגלל אופקית. הלשונית הפעילה נשמרת ב־hash (`/admin#blog`).
- פג תוקף החיבור (401 מכל קריאה) → חזרה למסך הכניסה עם הודעה.

### 3.3 לידים
- מונים: הכול / חדש / בטיפול / נסגר.
- סינון: סטטוס, סוג (צור קשר / בהתאמה אישית), חיפוש חופשי (שם, טלפון, מייל, יעד, הודעה).
- כרטיס פנייה: כל הפרטים הקיימים + בורר סטטוס + הערות פנימיות (הוספה; כל הערה עם תאריך) + וואטסאפ/חיוג.
- כפתור „ייצוא CSV” (לפי המסננים הנוכחיים בצד השרת: status, type, q).
- מצבים: טוען; ריק („אין עדיין פניות”); אין תוצאות לסינון; שגיאה.

### 3.4 בלוג
- רשימה: כל הפוסטים (מובנים + שנוצרו), עם תגית מצב: „מפורסם”, „טיוטה”, „מתוזמן” (תאריך עתידי), „מובנה”, „מובנה · נערך”, „מוסתר”.
- „פוסט חדש” / „עריכה” פותחים עורך:
  - כותרת*, כתובת (slug, אותיות לטיניות קטנות/ספרות/מקף; נוצר אוטומטית), קטגוריה, תמונת שער (URL או העלאת קובץ — מוקטן בדפדפן ל־1200px JPEG; עד 350KB אחרי קידוד), תקציר, גוף ב־Markdown* עם תצוגה מקדימה חיה (זה לצד זה במחשב, אחד מתחת לשני בטלפון), תגיות (מופרדות בפסיקים), תאריך פרסום, כותרת ותיאור SEO.
  - כפתורים: „שמירת טיוטה”, „פרסום” / „הסרה מפרסום”, „מחיקה” (אישור), „גרסאות קודמות” (שחזור).
- פוסט מובנה: בעריכה הראשונה נוצר עותק ב־KV עם אותו slug, שגובר על המובנה. מחיקת פוסט מובנה = הסתרתו (ניתן להחזיר). „חזרה לנוסח המקורי” מוחקת את העותק.

### 3.5 תוכן האתר
טופס אחד עם קבוצות, כל שדה עם ערך ברירת המחדל כ־placeholder ו„ריק = ברירת מחדל”:
- דף הבית: כותרת ראשית, תת־כותרת.
- פרטי קשר: וואטסאפ (ספרות בינלאומיות, למשל 972501234567), טלפון, מייל.
- פוטר: שורת מותג, משפט קצר, שורת זכויות/הבהרה.
- באנר הודעה: מופעל/כבוי, טקסט, קישור (אופציונלי, `#/…` או `https://…`).
- שאלות נפוצות: רשימה (שאלה + תשובה), הוספה/מחיקה/סידור; ריקה = השאלות המובנות.
- מדריכי יעדים: לכל יעד מובנה — „למי מתאים”, „פחות מתאים ל”, „איפה לישון”, „להתנייד”, „מתי לנסוע”, „מה מייקר”.
- „שמירה”, „גרסאות קודמות” (שחזור), הודעת הצלחה/שגיאה ליד הכפתור.

### 3.6 שער מטבע
- בורר מטבע (USD/EUR) + שער לשקל + „שמירה” + „ביטול שער ידני”.
- קורא `GET /api/fx` להצגת השער הנוכחי וכותב `PUT /api/fx/override` (יכולת של צוות המחירים). 404 → „היכולת עוד לא זמינה בשרת הזה”.

### 3.7 שיחות שירות
- קורא `GET /api/support/escalations` (יכולת של צוות הבוט) ומציג רשימה כללית (תאריך, שם, טלפון, נושא/סיכום, סטטוס; שדות לא מוכרים — טקסט מוברח). 404 → „היכולת עוד לא זמינה”.

## 4. מודל נתונים (KV, namespace `content` ו־`admin`)

| מפתח | ערך | הגבלות |
|---|---|---|
| `admin:session:<sha256(id)>` | `{ createdAt, ua }`, TTL 12 שעות | מזהה אקראי 32 בתים; ב־KV נשמר רק ה־hash |
| `leads:meta` (namespace leads) | `{ [leadId]: { status, notes:[{at,text}], updatedAt } }` | עד 20 הערות לפנייה, 1000 תווים להערה |

פוסט: `{ slug, title(≤120), category(≤40), excerpt(≤300), body(≤40000), tags[≤8, כל אחת ≤30], cover(URL https או /assets/… או /api/content/cover/<slug>), publishDate(YYYY-MM-DD), status('draft'|'published'), seoTitle(≤70), seoDescription(≤160), builtin(bool), createdAt, updatedAt }`.

## 5. חוזה API

אימות: עוגיית `gerbi_admin` (HttpOnly, SameSite=Strict, Path=/, Secure ב־HTTPS, 12 שעות). כל כתיבה דורשת `Content-Type: application/json` ו־Origin תואם (אם נשלח). בקשה עם עוגייה תקפה ל־`/api/*` בלי Authorization מקבלת בשרת `Authorization: Bearer <LEADS_ADMIN_TOKEN>` — כך נקודות קצה של צוותים אחרים שבודקות את אותו מפתח (`/api/leads`, `/api/fx/override`, `/api/support/escalations`) עובדות מהממשק בלי שהמפתח יגיע לדפדפן.

| שיטה ונתיב | הרשאה | תיאור |
|---|---|---|
| POST `/api/admin/login` `{password}` | ציבורי, 5 ניסיונות ל־10 דקות לכתובת | 204 + עוגייה; 401; 429; 404 אם אין LEADS_ADMIN_TOKEN |
| POST `/api/admin/logout` | עוגייה | מוחק סשן ומנקה עוגייה, 204 |
| GET `/api/admin/session` | עוגייה | `{ok:true, storage}` או 401 |
| GET `/api/admin/leads?status&type&q&limit` | עוגייה | פניות + meta, החדשה ראשונה, `counts` |
| PATCH `/api/admin/leads/<id>` `{status?, note?}` | עוגייה | מעדכן סטטוס / מוסיף הערה |
| GET `/api/admin/leads.csv?status&type&q` | עוגייה | CSV עם BOM, תאים מוגנים מנוסחאות (`=+-@`) |
| GET `/api/admin/blog` | עוגייה | כל הפוסטים מה־KV (כולל טיוטות) + `hidden` |
| GET `/api/admin/blog/<slug>` | עוגייה | פוסט מלא |
| PUT `/api/admin/blog/<slug>` | עוגייה | יצירה/עדכון; `coverData` אופציונלי (data URL) |
| DELETE `/api/admin/blog/<slug>` | עוגייה | מחיקה; לפוסט מובנה עם `?hide=1` — הסתרה |
| POST `/api/admin/blog/<slug>/unhide` | עוגייה | ביטול הסתרת מובנה |
| GET `/api/admin/blog/<slug>/versions` · POST `…/restore {index}` | עוגייה | גרסאות ושחזור |
| GET/PUT `/api/admin/site` · GET `/api/admin/site/versions` · POST `/api/admin/site/restore {index}` | עוגייה | תוכן האתר |
| GET `/api/content/site` | ציבורי | הדריסות בלבד; `Cache-Control: public, max-age=60` |
| GET `/api/content/blog` | ציבורי | פוסטים מפורסמים שתאריכם הגיע (בלי גוף) + `hidden` |
| GET `/api/content/blog/<slug>` | ציבורי | פוסט מפורסם מלא; 404 לטיוטה/מתוזמן |
| GET `/api/content/cover/<slug>` | ציבורי | התמונה עצמה (בינארי), `Cache-Control` ארוך |
| GET `/admin` · `/leads-admin` | ציבורי | הדף (noindex, no-store) · הפניה 301 ל־`/admin` |

קודי שגיאה: 400 `invalid` עם `fields`, 401 `unauthorized`, 403 `bad_origin`, 404, 409 `slug_taken`, 413 `payload_too_large`, 415 `json_required`, 429.

## 6. אבטחה
- הסיסמה לא נשמרת בדפדפן; השוואה בזמן קבוע (hash באורך קבוע).
- סשן בצד השרת (KV) — יציאה מבטלת אותו באמת. העוגייה HttpOnly + SameSite=Strict (הגנת CSRF), ובנוסף בדיקת Origin על כתיבות.
- הגבלת קצב: כניסה 5/10 דק׳; קריאות ניהול 120/דקה.
- Markdown: מנוע קטן בבית — escape לכל הטקסט קודם, ואז רשימה סגורה של תחביר (כותרות, הדגשה, קישורים, רשימות, ציטוט, תמונה). קישורים רק `https:`, `http:`, `mailto:`, `tel:`, `#/`, `/`; תמונות רק `https:` או `/assets/` או `/api/content/cover/`. קישורים חיצוניים עם `rel="noopener noreferrer nofollow"`.
- כל טקסט מתוכן האתר מוצג עם escape (גם שאלות נפוצות ומדריכי יעדים, שבעבר הוצגו כ־HTML מהקוד).
- תמונות: רק data URL של `image/jpeg|png|webp`, עד 350KB; מוגשות עם Content-Type מהרשימה ו־`nosniff`. SVG אסור.
- `/admin` עם `X-Robots-Tag: noindex, nofollow`, `Cache-Control: no-store`, `Referrer-Policy: no-referrer`.
- אם `LEADS_ADMIN_TOKEN` לא מוגדר — אזור הניהול לא קיים (404).

## 7. מקרי קצה
- ה־API למטה / KV לא זמין: האתר מציג ברירות מחדל (ועותק אחרון שנשמר בדפדפן); הניהול מציג שגיאה ברורה ולא מאבד את הטופס.
- slug כפול בפוסט חדש → 409 והודעה; שינוי slug של פוסט קיים אינו נתמך (מוחקים ויוצרים).
- תאריך פרסום עתידי → „מתוזמן”, לא מופיע באתר עד התאריך.
- פוסט מובנה שהוסתר → `#/blog/<slug>` מחזיר „הדף לא נמצא”.
- כותרת בעברית → slug אוטומטי `post-YYYYMMDD-xxxx`; ניתן לשנות לפני שמירה ראשונה.
- תמונה גדולה מדי גם אחרי הקטנה → הודעת שגיאה, הפוסט לא נשמר.
- שני חלונות עורכים אותו פריט → האחרון גובר (עורך יחיד; מתועד, לא נפתר).
- פנייה שנמחקה מהרשימה (מעבר ל־5000) → ה־meta שלה נשאר יתום ונמחק בעדכון הבא.
- רענון אחרי שינוי תוכן: האתר מושך את התוכן פעם אחת בטעינה (מטמון 60 שניות ב־CDN).

## 8. קריטריוני קבלה
1. `/admin` מציג מסך כניסה; `/leads-admin` מפנה (301) ל־`/admin`; שניהם noindex.
2. כניסה עם `LEADS_ADMIN_TOKEN` יוצרת עוגייה HttpOnly+SameSite=Strict; שום מפתח/סיסמה לא נשמרים ב־localStorage/sessionStorage.
3. סיסמה שגויה → 401; הניסיון השישי בתוך 10 דקות → 429.
4. יציאה מבטלת את הסשן: אותה עוגייה מקבלת 401 אחר כך.
5. בלי עוגייה כל `/api/admin/*` (מלבד login) מחזיר 401.
6. כתיבה עם Origin זר → 403; כתיבה שאינה JSON → 415.
7. לידים: רשימה עם מונים, סינון לפי סטטוס/סוג/חיפוש, שינוי סטטוס והערה נשמרים ונראים אחרי רענון.
8. CSV: כולל BOM, כותרות בעברית, ותא שמתחיל ב־`=` מנוטרל.
9. בלוג: יצירת פוסט, טיוטה לא מופיעה ב־`/api/content/blog`, פרסום מופיע, הסרה מפרסום מעלימה, מחיקה מוחקת.
10. פוסט מתוזמן לא מופיע עד התאריך.
11. עריכת פוסט מובנה יוצרת עותק שגובר; הסתרה מעלימה אותו מהאתר; ביטול הסתרה מחזיר.
12. `#/blog` ו־`#/blog/<slug>` מציגים מובנים + פוסטים מה־API, ועובדים גם כשה־API מחזיר שגיאה.
13. כותרת/תיאור SEO של פוסט מעדכנים את `document.title` ו־`meta[name=description]`.
14. Markdown: `<script>`, `javascript:`, `onerror=` ותגיות HTML מוצגים כטקסט ולא מורצים (בדיקות יחידה).
15. תמונה: data URL מעל 350KB או מסוג לא מותר → 400; תמונה תקינה מוגשת עם Content-Type נכון.
16. תוכן האתר: שינוי כותרת דף הבית, פרטי קשר, באנר ופוטר מופיע באתר הציבורי אחרי טעינה; ערך ריק חוזר לברירת המחדל.
17. פרטי הקשר מ־`/api/content/site` גוברים על `dist/data.mjs` (קישורי וואטסאפ/טלפון/מייל).
18. שאלות נפוצות ומדריכי יעדים נערכים ומוצגים עם escape.
