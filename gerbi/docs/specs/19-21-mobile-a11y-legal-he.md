# אפיון 19–21 — התאמה לנייד, נגישות (ת״י 5568) ודפים משפטיים

תאריך: 15.11.2026 · סטטוס: מאושר לפיתוח · בעלים: סוכן Mobile / A11y / Legal

שלושה תחומים שנבדקים יחד כי הם נוגעים באותם מסכים: **19** התאמה לנייד, **20** נגישות לפי ת״י 5568 (WCAG 2.0/2.1 AA), **21** דפים משפטיים (תנאי שימוש, פרטיות) — כטיוטות לבדיקת עורך דין.

## 1. עקרונות

- תיקונים אמיתיים בקוד ובעיצוב — לא „תוסף נגישות” (overlay). סרגל פשוט של גודל טקסט וניגודיות מותר כתוספת, לא כתחליף.
- שינויים כירורגיים: CSS בקובץ ייעודי שנטען אחרון (`dist/a11y-mobile.css`), דפים חדשים במודול נפרד (`dist/legal.mjs`), עריכות קטנות בלבד בקבצים קיימים (סוכנים אחרים עובדים במקביל על חיפוש רב־יעדי ושכבת AI).
- אין תלות runtime חדשה. axe-core נטען לבדיקה בלבד מתוך עותק מקומי.
- המותג „ג׳רבי טורס” בלבד; שם הספק לא מופיע בממשק.
- התנהגות `.pointer-nav` (הסתרת מסגרת פוקוס אחרי לחיצת עכבר בלבד) נשמרת; מקלדת תמיד רואה פוקוס.

## 3. שיטה

1. **סקריפט ביקורת** (`tests/e2e/a11y-mobile.audit.mjs`, Playwright): לכל מסלול ולכל רוחב מודד גלילה אופקית (`scrollWidth > innerWidth`), יעדי מגע קטנים מ־44×44 (24×24 מינימום WCAG 2.2 לאלמנטים בתוך טקסט), גופן קטן מ־12px, חפיפת אלמנטים קבועים (סרגל תחתון / משגר בוט / טוסט), ומריץ axe-core (תגיות `wcag2a, wcag2aa, wcag21a, wcag21aa`). תוצאות JSON + צילומי מסך „לפני/אחרי” ב־`verification/19-21-mobile-a11y/`.
2. **מעבר מקלדת בלבד**: Tab מהדילוג לתוכן דרך התפריט, הטופס, בורר התאריכים, דיאלוג ובוט; Escape סוגר; הפוקוס חוזר לכפתור הפותח.
3. **סקירת סמנטיקה לקורא מסך**: landmarks, סדר כותרות, תוויות, `aria-live`, דיאלוגים, `lang/dir`.
4. **זום 200% / רוחב 320px** (reflow, WCAG 1.4.10), **prefers-reduced-motion**, **landscape** (‎844×390).

## 5. רשימות בדיקה

### 5.1 נייד (19)
- [ ] אין גלילה אופקית בשום מסלול ורוחב.
- [ ] יעדי מגע עיקריים ≥ 44×44px (כפתורים, קישורי ניווט, סגירת דיאלוג, צ׳יפים, לחצני +/− בנוסעים, ימי לוח שנה ≥ 40px).
- [ ] גופן גוף ≥ 16px בשדות קלט (מונע זום אוטומטי ב־iOS); טקסט משני ≥ 12px.
- [ ] אלמנטים קבועים לא חופפים: סרגל ניווט תחתון, משגר הבוט, טוסט, מגש השוואה — כולם מעל `env(safe-area-inset-bottom)`.
- [ ] דיאלוגים (בורר תאריכים, נוסעים, בדיקת מחיר, מודל כללי, חלון הבוט) במסך מלא או כמעט־מלא בטלפון, עם גלילה פנימית וכפתור סגירה נגיש.
- [ ] שדות: `type`/`inputmode`/`autocomplete` נכונים (tel, email, name, numeric); שדה בפוקוס לא מוסתר ע״י מקלדת (scroll-margin + גלילה לתצוגה).
- [ ] safe-area: `viewport-fit=cover` + ריפוד בפינות.
- [ ] landscape: הדיאלוגים נגללים ולא נחתכים.

### 5.2 נגישות (20)
- [ ] 0 הפרות axe ברמות serious/critical בכל המסלולים; הפרות moderate/minor מתועדות.
- [ ] landmarks: header/banner, nav עם שם, main יחיד, footer/contentinfo.
- [ ] כותרת h1 אחת לכל מסך, ללא דילוג רמות.
- [ ] כל שדה עם תווית נגישה; שגיאות מקושרות (`aria-describedby`) ומוכרזות.
- [ ] ניגודיות טקסט ≥ 4.5:1 (טקסט גדול 3:1); רכיבי ממשק וגבולות שדות ≥ 3:1.
- [ ] פוקוס נראה לכל אלמנט אינטראקטיבי (מקלדת), סדר פוקוס הגיוני, אין מלכודת פוקוס מחוץ לדיאלוג.
- [ ] קישור דילוג לתוכן עובד.
- [ ] `aria-live` לטוסטים, תוצאות חיפוש, הודעות טופס ותשובות בוט.
- [ ] דיאלוגים: `role=dialog`/`<dialog>`, שם נגיש, Escape, החזרת פוקוס.
- [ ] `prefers-reduced-motion` מבטל אנימציות; זום 200% בלי אובדן תוכן.
- [ ] סרגל נגישות פשוט (הגדלת טקסט, ניגודיות גבוהה, הדגשת קישורים) — נשמר במכשיר, לא מחליף תיקונים.
- [ ] הצהרת נגישות לפי תקנה 35 לתקנות שוויון זכויות לאנשים עם מוגבלות (התאמות נגישות לשירות), התשע״ג–2013.

### 5.3 משפטי (21)
- [ ] `#/terms` — תנאי שימוש ותנאים כלליים לסוכנות נסיעות (תפקיד הסוכנות מול חברות התעופה, מחירים עד הנפקה, בדיקת מחיר/הצעה, ביטולים ושינויים לפי כללי תעריף + דמי טיפול, חוק הגנת הצרכן ותקנות ביטול עסקה, הגבלת אחריות, דרכונים/אשרות, תשלום, פרטיות, דין ושיפוט, יצירת קשר).
- [ ] `#/privacy` — מעודכן לתיקון 13 לחוק הגנת הפרטיות: מטרות, קטגוריות מידע (חשבונות, פניות, שיחות בוט, עוגיות/אחסון מקומי), שמירה, זכויות, מעבדי מידע (אחסון, Upstash, מייל, WhatsApp, ספקי AI), יצירת קשר.
- [ ] שני הדפים מסומנים בבירור „טיוטה – לבדיקת עורך דין”. שאלות פתוחות לעורך הדין — במסמך פנימי (`docs/legal/`), לא בדף הציבורי.
- [ ] קישורים: פוטר, טקסט ההסכמה בטפסים, הרשמה לחשבון, תפריט נייד.
