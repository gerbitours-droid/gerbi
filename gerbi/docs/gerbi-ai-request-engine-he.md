# ג׳רבי AI — אלגוריתם הבנת הבקשה החופשית

29.10.2026 · קוד: `dist/brief-engine.mjs` (משותף לדפדפן ולשרת) · בדיקות: `tests/brief-engine.test.mjs`

המנוע הופך משפט חופשי בעברית לבקשה מובנית. הוא דטרמיניסטי ולא קורא למודל שפה, ולכן אותה בקשה תמיד מקבלת אותה תשובה, גם בדפדפן וגם בשרת. כל דבר שפוענח מוצג למשתמש עם המילים שממנו הגיע; כל הנחה נאמרת; כל עמימות הופכת לשאלה.

## הצינור

1. **נרמול** — NFKC, הסרת ניקוד, איחוד גרשיים ומקפים, מילות מספר לספרות („חמישה” → 5, „15 אלף” → 15000). „אחד/אחת” נשארות מילים, כי הן חלק מביטויים („כיוון אחד”, „ילד אחד”).
2. **חילוץ ישויות** (כל אחת מחזירה ערך + המילים שמהן נלקח):

| ישות | דוגמאות | כללים |
|---|---|---|
| נוסעים | „זוג”, „אנחנו 4 חברים”, „משפחה של 5”, „2 ילדים בני 4 ו־9”, „תינוק”, „בלי ילדים” | „N נוסעים/אנשים” = סה״כ, פחות ילדים; משפט שמתאר את כל הקבוצה מאפס ילדים מהודעה קודמת |
| תאריכים | „10-15 ביוני”, „מה־3.7 עד 8.7”, „ב־12 בדצמבר”, „בעוד שבועיים”, „סוף השבוע הבא”, „בפסח”, „בקיץ” | תאריך שעבר השנה → השנה הבאה; חג/עונה → חודש + שאלה על תאריך מדויק; ביטוי התאריך נצרך לפני חישוב משך |
| משך | „5 לילות”, „שבוע”, „שבוע וחצי”, „סופ״ש”, „5 ימים” | „N ימים” = N−1 לילות, ונאמר בגלוי |
| תקציב | „עד 12 אלף”, „3000 שקל לאדם”, „800 דולר” | רק סכום שמסומן ככסף (מילת מפתח או מטבע); לאדם × נוסעים; דולר/יורו לא מומרים בשקט — נשאלת שאלה |
| מקומות | „בפריז”, „ללונדון”, „מאילת”, „בלי דובאי”, „חוץ מרומא”, „רק רומא”, „ביוון” | ב/ל = יעד, מ = מוצא; שלילה עד שתי מילים אחורה; יעד חדש מחליף קודם (אלא אם „גם/או”); מדינה = כל יעדיה + שאלה „לאיזו עיר?”; נתב״ג/רמון/חיפה הם שדות בית, לא משאלת יעד |
| טיסה | „ישירה”, „עד עצירה אחת”, „לא לקום מוקדם”, „לחזור בערב”, „עם מזוודה”, „באל על”, „כיוון אחד” | הופכים למסננים גלויים בתוצאות, לא לסינון שקט |
| סגנון | ים, עיר/אוכל, מנוחה, משפחה, זוגי, כשר, שבת, נגישות | שלילה גוברת; „זוג עם ילדים” אינו חופשה זוגית |

3. **מיזוג עם הבקשה הקודמת** — ערך שנאמר עכשיו גובר; מה שלא נאמר נשאר. עריכות יחסיות: „עוד לילה”, „עוד ילד”, „תוריד את המחיר עד…”.
4. **שאלה הבאה** — לכל היותר שתיים, לפי מה שמשנה החלטה: עיר במדינה → יעד/סגנון → תאריכים מדויקים → ילדים/גילאים → לילות → תקציב (או מטבע).
5. **חיפוש חי** — מוצע רק כשיש יעד אחד שניתן לחפש ותאריך יציאה (וחזרה, בהלוך־חזור). הכפתור „חיפוש טיסות עכשיו” ממלא את הטופס, מפעיל חיפוש רגיל מול Volero ומחיל את ההעדפות כמסננים שאפשר להסיר.

## פלט

`understandRequest(text, previous, {today})` → `{ brief, understood[], assumed[], questions[], flightSearch|null }`.
`parsePreferences` (דפדפן) ו־`extractSignals` (שרת, מוסיף תגיות לשכבת הלמידה) עוטפים את אותו מנוע.

## מגבלות ידועות

- רשימת מקומות סגורה (`dist/places.mjs`): מקום שלא ברשימה מקבל שאלה, לא ניחוש.
- תאריכי חגים אינם מחושבים מלוח עברי — החג ממופה לחודש ונשאלת שאלה.
- גילאי ילדים נאספים אך עדיין לא נשלחים לספק (תמחור לפי גיל דורש מיפוי ptc לפי חוזה).
- שלב הבא אפשרי: מודל שפה כ„מפענח שני” רק למשפטים שהמנוע לא הבין, כשהפלט שלו עובר דרך אותם מבנים ואותן שאלות.
